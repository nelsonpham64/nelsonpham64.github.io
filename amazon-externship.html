Workforce Research

Amazon Workforce Sentiment & Burnout Analysis

An externship project using text analysis to study employee feedback, identify burnout signals, and translate findings into workforce recommendations.

Role Data analyst
Tools Python, pandas, NLTK, TextBlob
Focus Sentiment and theme analysis

Problem Statement

The project examined employee feedback to better understand common workplace themes and potential burnout indicators. The goal was to move from raw, unstructured text into a practical set of findings that could inform workforce recommendations.

Python pandas NLTK TextBlob Externship

Data Overview

The analysis used more than 130 feedback records gathered from Glassdoor reviews and YouTube transcript content. The two sources provided different views into employee sentiment and workplace concerns.

Glassdoor Reviews

Employee-written feedback that helped surface recurring themes about workplace expectations, pressure, and support.

YouTube Transcripts

Transcript text that added more context around employee experiences and public discussion.

Methodology

The project followed an end-to-end text analysis workflow in Google Colab. Raw text was cleaned, standardized, tokenized, and prepared for sentiment and keyword exploration.

Preprocessing

Cleaned text by removing noise, standardizing casing, and preparing words for analysis.

Sentiment Review

Used sentiment scoring and keyword review to identify patterns in positive, negative, and neutral comments.

Theme Grouping

Grouped recurring terms and comments into broader workplace themes.

Recommendation

Translated the analysis into practical suggestions tied to employee support and burnout reduction.

Key Findings

  • Burnout-related language appeared around workload, pace, schedule pressure, and perceived support.
  • Employee feedback contained both operational concerns and positive comments about growth opportunities.
  • Text analysis helped turn scattered feedback into themes that were easier to discuss and prioritize.
  • The strongest recommendations were tied to manager support, workload expectations, and clearer employee feedback loops.

What I Did

  • Built a text preprocessing workflow in Python.
  • Applied keyword and sentiment analysis techniques to unstructured feedback.
  • Grouped findings into stakeholder-friendly themes.
  • Created presentation materials to communicate the analysis and recommendations.
