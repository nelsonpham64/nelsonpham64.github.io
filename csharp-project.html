Bakery Vending Machine

ISDS 309 - C# Programming Project

C# .NET Windows Forms File I/O

Project Overview

This program is a fully functional bakery vending machine application that allows users to choose from four different beverages and two food items, displaying the total after selecting the quantity of each product.

Using this program, users can create an order, complete payment, and receive a printed receipt showing the order number, items purchased, payment method, and total dollar amount including tax.

🖥️ Application Interface Screenshot (Vending.png)

Key Features

🔐 User Authentication System

Secure login functionality with username and password verification. Login credentials are stored in a text file, allowing for easy addition of new users and passcodes. All login attempts are tracked with timestamps and success status.

📝 Activity Logging

Comprehensive activity log that tracks all login attempts including username, time, date, and success status. This provides a complete audit trail for security and usage monitoring.

🛒 Shopping Cart System

Interactive order management where users can select multiple items, adjust quantities, and view real-time order summaries. Includes a "Clear Cart" function to start over if needed.

💳 Payment Processing

Complete checkout flow with payment information collection. Users can review their total before proceeding to payment or cancel to modify their order.

🧾 Receipt Generation

Automatic receipt printing after completed payment. Receipts include order number, itemized list of purchases, payment method, subtotal, tax, and grand total.

Technical Implementation

File-Based Data Management

The application uses text files for persistent data storage:

  • Login.txt: Stores user credentials (username and password pairs)
  • ActivityLog.txt: Records all login attempts with timestamp and status
  • Products.txt: Contains product catalog with names and prices
  • Receipt.txt: Generates formatted receipt for completed transactions

User Workflow

  1. User logs in with credentials → validated against Login.txt
  2. Successful login displays product selection interface
  3. User selects items and quantities → order summary updates in real-time
  4. User reviews total and proceeds to checkout
  5. Payment information collected and validated
  6. Receipt generated and saved to Receipt.txt
  7. Option to place another order or exit application

Technologies Used

  • C# Programming Language: Core application logic
  • Windows Forms: Graphical user interface
  • File I/O Operations: Data persistence and logging
  • .NET Framework: Application runtime environment
  • Visual Studio: Development environment
